# Server discovery

This Rust capability owns stable installation identity, Eitmad Discovery v1 datagrams,
bounded scans and responder lifecycle, Private-interface policy, and untrusted candidate
projection. The Windows interface adapter reads network profiles without changing them.
Contracts remain in `eitmad-contracts`; local IPC owns bootstrap-channel authorization.
The server host composes advertising. Discovery has no trust, enrollment, secret-store,
product storage, or access-grant dependency.

See [discovery operation and protocol](../../docs/developer/subsystems/server-discovery.md).
